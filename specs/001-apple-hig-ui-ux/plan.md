# Implementation Plan: Cải tiến UI/UX theo triết lý Apple HIG

**Branch**: `001-apple-hig-ui-ux` | **Date**: 2026-04-21 | **Spec**: [spec.md](./spec.md)  
**Input**: Feature specification from `/specs/001-apple-hig-ui-ux/spec.md`

## Summary

Refactor toàn bộ hệ thống UI của SoiToaDoVN theo triết lý Apple HIG: thiết lập design token tập trung (`src/theme/`), xây dựng các shared component tái sử dụng (`ScreenHeader`, `Toast`, `SettingsSection`/`SettingsRow`), thay thế `Alert.alert()` thành công bằng toast tự ẩn, sửa safe area padding hardcode, bổ sung haptic feedback, và tái cấu trúc hierarchy CTA trên HomeScreen. Toàn bộ thay đổi là UI-only — không ảnh hưởng logic nghiệp vụ.

---

## Technical Context

**Language/Version**: TypeScript 6.x strict / React Native 0.81.5 / Expo SDK 54  
**Primary Dependencies**:
- `react-native-reanimated` v4.1.x — Toast animation (already installed)
- `react-native-gesture-handler` v2.28.x — swipe-to-dismiss Toast (already installed)
- `react-native-safe-area-context` v5.6.x — `useSafeAreaInsets`, `useBottomTabBarHeight` (already installed)
- `expo-haptics` — **new, must add via `pnpm add expo-haptics`**
- `lucide-react-native` v0.563.x — icons (already installed, unified in TS migration)

**Storage**: N/A — no new persisted data  
**Testing**: Jest + RNTL (to be added per constitution gate III)  
**Target Platform**: iOS 15+ / Android 10+ (API 29+)  
**Project Type**: Mobile app (React Native / Expo managed)  
**Performance Goals**: Toast animation 60fps; no jank on low-end Android  
**Constraints**: Single codebase — no platform forks; offline-capable; light mode only  
**Scale/Scope**: 11 screens + 3 new shared components + 1 theme module
